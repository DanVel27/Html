Каскадні таблиці стилів: CSS

Частково про CSS зазначають у

Реомендований спосіб додавати стилі для всього сайту - це оремий файл, що підключається за допомогою тегу link у заголовку сторінки. Суть файлу - це послідовне застосування стилів для груп елементів, які потрапляють до селекторів. Можна сказати, що кожна команда CSS-файлу має структуру: (Знайте все, що відповідає такому-то селектору) { і застосувати до нього даний набір стилів } 

    (Знайте все, що відповідає такому-то селектору) {
        і застосувати 
        до нього даний 
        набір стилів
    }

Термін "каскадний" стверджує те, що кожна наступна команда буде поєднуватись з попередніми.

Основні селектори

Селектор Значення
* Всі елементи
img Всі елементи, що мають тег <img />
.middle Всі елементи, в яких зазначено class="middle"
.selector-table th Всі елементи <th>, які знаходяться в середині елементів з class="selector-table". Взаглі, пробіл між селекторами означає "в середині", пробілом можуть розділятись і інші види селекторів. Наприклад, "p b" - всі теги <b> в середині параграфів (<p>); "bold .small" - всі елементи з клласом "small" в середині елементів з класом "bold"
p, b Кома позначає "та" - спільні стилі для двох (і більше) селекторів
