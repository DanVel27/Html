Форми HTML

Форми - "форми зворотнього зв'язку" - спецціальні елементи, які дозволяють вводити дані користувачеві та передавати їх да серверної частини сайту. Форма задається тегом <form> і поєднує окремі елементи, що будууть передані разом.

Елементи форм

Назва Приклад Призначення
Text Введення звичайного тексту
E-mail Введення електронної пошти
Password Введення пароля
Number Введення числа
Date Вибір дати
Time Вибір часу
Color Вибір кольору
Range Вибір значення за допомогою повзунка
Checkbox Вибір одного або декількох пунктів
Radio Вибір одного варіанта
File Вибір файлу з комп'ютера
Search Поле для пошуку
Select Виберіть напой Вибір варіанта зі списку
Textarea Введення великого тексту
Button Кнопка для виконання дії
Submit Відправлення форми
Reset Очищення полів форми
