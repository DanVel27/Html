DOCTYPE — это объявление типа HTML-документа.
Оно указывается в самом начале HTML-файла и сообщает браузеру,
какая версия или стандарт HTML используется.

1. HTML5

<!DOCTYPE html>

Современный и самый простой вариант DOCTYPE.
Используется в HTML5 и современных веб-сайтах.


2. HTML 4.01 Strict

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01//EN"
"http://www.w3.org/TR/html4/strict.dtd">

Использовался в HTML 4.01.
Strict означает строгий стандарт без устаревших элементов.


3. HTML 4.01 Transitional

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN"
"http://www.w3.org/TR/html4/loose.dtd">

Позволял использовать некоторые устаревшие HTML-теги
и атрибуты.


4. HTML 4.01 Frameset

<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Frameset//EN"
"http://www.w3.org/TR/html4/frameset.dtd">

Использовался для страниц, в которых применялись фреймы.


5. XHTML 1.0 Strict

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">

Строгая версия XHTML 1.0.


6. XHTML 1.0 Transitional

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Transitional//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-transitional.dtd">

Более свободная версия XHTML 1.0,
которая позволяла использовать некоторые старые элементы.


7. XHTML 1.0 Frameset

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Frameset//EN"
"http://www.w3.org/TR/xhtml1/DTD/xhtml1-frameset.dtd">

Использовался в XHTML-страницах с фреймами.


8. XHTML 1.1

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.1//EN"
"http://www.w3.org/TR/xhtml11/DTD/xhtml11.dtd">

Более строгая версия XHTML.
